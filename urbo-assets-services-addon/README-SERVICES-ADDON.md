# URBO services asset add-on

These files were extracted from the existing services embed and optimised for external hosting.

## Add them to the existing GitHub repository

1. Open `filipurbanskidesign-ux/urbo-assets` on GitHub.
2. Choose **Add file → Upload files**.
3. Open this extracted package.
4. Drag the `images` folder into GitHub.
5. Confirm the upload paths begin with:
   - `/images/services/olivers-website-desktop-large.webp`
   - `/images/services/unicorn-office-interior-large.webp`
6. Commit with:
   `Add services embed image assets`

After Vercel redeploys, use the included updated Hostinger embed:
`urbo-services-transparent-external-images.html`
